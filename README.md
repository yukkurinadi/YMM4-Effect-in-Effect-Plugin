# YMM4 エフェクト内エフェクトプラグイン (EffectInEffectPlugin)

ゆっくりMovieMaker4 (YMM4) 用の映像エフェクトプラグイン**「エフェクト内エフェクト」**です。
すべての映像エフェクトに対して、さらに内側エフェクトをかけられるようになります。
影だけぼかす・縁取りだけモザイクをかけるといった演出に最適です。

## 主な機能・特徴

1. **すべての映像エフェクトに対応**
YMM4標準のエフェクト選択UIにより、任意の映像エフェクトを対象にできます。

2. **変化部分のみに適用**
対象エフェクトが変化させた部分にだけ内側エフェクトを合成します。
変化していない部分は元のまま残ります。

3. **全体モード**
対象エフェクトの適用結果全体に内側エフェクトをかける方式にも切り替え可能です。

4. **無制限の入れ子対応**
このエフェクト自体を内側に入れることもできるため何重にも重ねられます。

5. **軽量な合成処理**
合成はGPU上の1パスで完結し、直列適用比で約3%の上乗せに収まります。

------------------------------------------------------------------------
## 設定パラメータ一覧

| 項目名 | 説明 |
|---|---|
| **かけられるエフェクト** | エフェクトをかけられる側（対象）の映像エフェクト |
| **かけるエフェクト** | 対象の適用結果に対してかける内側エフェクト |
| **適用範囲** | 内側エフェクトを適用する範囲（変化部分のみ / 全体） |

------------------------------------------------------------------------
## インストール方法

【自動】
EffectInEffectPlugin.ymmeを開くと自動でインストールされます。

【手動】
このプラグインのzipまたはdllファイルを取得して、
`C:\YMM4\user\plugin\EffectInEffect\EffectInEffectPlugin.dll`
と配置してください。EffectInEffect フォルダは作成してください。
YMM4 を起動（または再起動）すると、エフェクト一覧に「**エフェクト内エフェクト**」が追加されます。

------------------------------------------------------------------------
## 注意

AviUtl形式（.exo）への出力には対応していません。

「変化部分のみ」では合成処理が1パス増えるため少し重くなります。
重いと感じた場合は縁取りのぼかし・品質やモザイクのブロックサイズ、プレビュー解像度を見直してください。
